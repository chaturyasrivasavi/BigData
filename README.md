# BigData
PROJECT: Improving Student Outcomes Through Predictive Analytics

Technologies Used: Python, PySpark, Pandas, Unix, MongoDB

Developed a predictive analytics project to analyze student performance and identify factors affecting academic outcomes.
Used Python and Pandas for data cleaning, preprocessing, and exploratory data analysis.
Utilized PySpark to process and analyze large datasets efficiently.
Used MongoDB for storing and managing student-related data.
Applied predictive analytics techniques to identify students who may need additional academic support.
Used Unix commands for file handling and data processing.

Objective: To leverage data analytics and predictive techniques to identify students at academic risk and support improved educational outcomes.
